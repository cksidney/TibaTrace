# Windows POS 1.0.14 (build 14)

Includes direct RX intake, photo/PDF uploads, source preview, branch inbox and
governed legal/clinical/pharmacist review. When the server explicitly defers
malware scanning, upload remains available with a clear notice and stored sources
show **Not malware scanned**. The upload does not approve the prescription.

Requires rc59 or a compatible backend and the document encryption keyring.
External EMR/DHA and payment connections remain tenant-specific commissioning
work. The upgrade is advisory; the minimum supported build is unchanged.

Publish only after signature, timestamp, branding, clean-install and bridge
acceptance checks pass and the compatible backend is active.
