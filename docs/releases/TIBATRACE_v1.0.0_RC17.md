# TibaTrace v1.0.0-rc17

RC17 corrects Platform Owner recognition for the controlled Nairobi Chemists
demo-tenant workflow.

## Included

- Recognise active platform administrators as Platform Owners when executing
  the audited `designate_demo_tenant` command.
- Retain the existing strict tenant identity confirmation and audit event for
  every demo designation.
- Add automated coverage for the Platform Administrator authorization path.

## Not included

No tenant data is generated by this release. Production scenario generation
still requires a designated demo tenant, a recent backup and an unexpired
approval from a different Platform Owner for the exact manifest digest.
