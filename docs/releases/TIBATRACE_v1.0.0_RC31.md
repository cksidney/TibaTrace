# TibaTrace v1.0.0-rc31 — compact HQ password-change screen

This HQ-only follow-up reduces the password-change card width, padding, vertical
gaps and input/button heights while preserving the readable labels, focus state,
password guidance, error messages and responsive mobile layout introduced in
rc30.

The release has no backend business-code changes and no database migrations.
API, worker, beat and POS release versions remain unchanged.
