# TibaTrace v1.0.0-rc18

RC18 corrects the final safety-classification edge case in the controlled
Nairobi Chemists demo workflow.

## Included

- Treat exactly one successful, fully matching `DEMO_TENANT_DESIGNATED` audit
  event as required governance infrastructure for an otherwise empty demo
  tenant.
- Preserve the fail-closed boundary: any additional, incomplete or unrelated
  audit event remains unclassified and blocks seeding.
- Add positive and negative automated tests for the audit classification rule.

## Not included

No tenant data is generated by this release. The production scenario still
requires an unexpired approval from a Platform Owner other than the requester
for the exact manifest digest.
