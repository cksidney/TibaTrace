# TibaTrace v1.0.0-rc16

RC16 is a narrow production safety hotfix for the Nairobi Chemists demo
scenario gate.

## Included

- Classify exactly one active, unassigned system `TENANT_ADMIN` role as
  bootstrap provisioning state rather than unexplained business data.
- Keep the fail-closed boundary intact: assigned roles, custom roles and every
  clinical, commercial or transactional record remain unclassified and block a
  demo seed.
- Generate release evidence from the versioned release note rather than a
  hard-coded prior release document.

## Not included

No Nairobi Chemists data is generated by this release. A production seed still
requires explicit tenant designation, a recent backup, and an unexpired
Platform Owner approval from a different person for the exact manifest digest.
